# Adriel Toto portfolio

Open `index.html` in a browser to preview. Everything needed for the layout and gallery is included. The project and contact links open external sites or your email app.

Edit the text, navigation, and links in `index.html`. Edit the colors, typography, and responsive layout in `style.css`. The images, icon, and local font are in `portfolio-assets/`. The hero uses a transparent PNG based on the CV headshot. Use another transparent image when replacing it, and update its width and height in `index.html`. Keep that directory beside the HTML and CSS.

## Publish to the existing GitHub Pages site

1. Sign in to [Adsign143/Assign143.github.io](https://github.com/Adsign143/Assign143.github.io) with an account that can write to the repository.
2. In **Settings → Pages**, check the existing publishing source. For **Deploy from a branch**, note the branch and folder. For **GitHub Actions**, check which folder the existing workflow publishes.
3. Copy `index.html`, `style.css`, and the entire `portfolio-assets/` folder to that source, replacing the current HTML and CSS. Keep the repository's other files and Pages settings. If uploading through the GitHub website, use **Add file → Upload files** and keep the assets in their folder.
4. Commit the changes to the publishing branch or merge a pull request into it. Check **Actions** for a successful Pages run, then open the [live portfolio](https://adsign143.github.io/Assign143.github.io/).

[GitHub Pages publishing guide](https://docs.github.com/en/pages/getting-started-with-github-pages/configuring-a-publishing-source-for-your-github-pages-site)

## Activate contact form email delivery

1. Publish the updated portfolio and open the form on your live GitHub Pages URL.
2. Submit a test message. FormSubmit will send an activation email to totoadriel8@gmail.com. Check Spam if it does not arrive in your inbox.
3. Open the activation email and confirm the form. Submit a second test from the live page and verify it arrives in Gmail.

FormSubmit processes the contact form submissions and may show a CAPTCHA or confirmation page. The contact panel also lists the Gmail address for direct email.

[FormSubmit setup guide](https://formsubmit.co/)
